# 专题：算法基础（复杂度分析）

> 这一页是示范密度：概念 + 自己的推论 + 实用速查，一页纸内。照这个密度填其他专题。

## 核心思想

大 O 描述「输入规模增长时，耗时增长几倍」的趋势，忽略常数和低阶项。它决定一个方案在给定数据规模下能不能过——面试里它就是判断方案够不够用的标尺。

## 实用速查：数据规模 → 目标复杂度

拿到题先看数据范围，反推复杂度上限，再选算法——这是面试最实用的技巧。

| 数据规模 n | 可接受复杂度 | 常见对应算法 |
|---|---|---|
| ≤ 20 | O(2ⁿ) | 回溯 / 爆搜 |
| ≤ 500 | O(n³) | 小规模 DP |
| ≤ 5000 | O(n²) | 二维 DP、双重循环 |
| ≤ 10⁶ | O(n log n) / O(n) | 排序、堆、双指针、哈希 |
| 更大 | O(log n) / O(√n) | 二分、数学 |

## 易错点

- 递归的空间复杂度要算调用栈深度，不只有显式开的数组；
- JS 的 `slice` / `spread` / `concat` 都是 O(n) 拷贝，放在循环里会把复杂度悄悄抬高一档；
- JS 没有内置堆（优先队列），用到时要手写或提前背好模板。
