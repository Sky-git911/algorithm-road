# practice/ · 本地实战区

流程：**本地写（脚手架）→ 跑本地测试 → 全过后贴函数去力扣提交 → 把结果告知老师（agent）**。

## 目录结构（按力扣难度分层）

```
practice/
├── Easy/           # lc0704 · lc0035 · lc0027 · lc0283 · lc0977
├── Medium/         # lc0034 · lc0033 · lc0153 · lc0011
├── Hard/           # （暂空，保持占位）
├── _template.js    # 起手模板（复制到对应难度目录后改名）
└── README.md
```

- 每题一文件：`lc<题号>-<slug>.js`，放进对应**难度目录**，从 `_template.js` 复制起手；
- 函数签名与力扣完全一致，**提交时只复制函数部分**（文件底部的本地测试不要贴）；
- 本地全过 ≠ 一定 AC：力扣还有隐藏用例，挂了回来想想哪个边界没覆盖，补进 CASES 再改；
- 25 分钟法则照旧：脚手架打开就开始计时；TS 党可自行加类型，提交时切力扣 JS/TS 标签即可。
