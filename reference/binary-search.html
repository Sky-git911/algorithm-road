前提（下笔前默念）

随机访问 + 判定单调（比较 mid 后能确定排除一侧；数组有序只是最常见的形态）。 不确定能不能排除一侧，就不能二分。

两种合同 · 决策对照表

决策点合同 A：左闭右闭 [l, r]合同 B：左闭右开 [l, r)
r 初始值n - 1n
循环条件l <= rl < r
a[mid] < tl = mid + 1（两种合同相同：mid 已比较过，必排除）
a[mid] > tr = mid - 1r = mid
区间为空l > rl ≥ r
命中a[mid] === t → 返回 mid（704 型）；变体题不急着返回，见下

不变量（每轮开始时成立）：若 t 存在，必在当前区间内。收缩语句只在维护这一句。

mid 的计算

mid = Math.floor((l + r) / 2) —— JS 首选。

JS 位运算 (l + r) >> 1 会截断成 32 位有符号整数，下标大时变负数。 口述加分项：C++/Java 用 l + (r - l) / 2 防溢出（JS 安全整数 2⁵³ 内不需要）。

复杂度速记

规模 n比较次数 ≈ log₂n线性扫描
10³~10 次1000 次
10⁵~17 次10 万次
10⁹~30 次已经超时了

时间 O(log n) · 空间 O(1)（迭代版）。口述时带上「空间为什么是 O(1)：只用了 l、r、mid 三个变量」。

边界版（0002）：lower_bound —— 找分隔点

「第一个 ≥ t 的位置」：35 的插入位、34 的左右边界都是它。仍是合同 B [l, r)，决策只有两条：

比较动作含义
a[mid] < tl = mid + 1mid 及左侧全部确认 < t，刀痕在右
a[mid] ≥ t（含 === t）r = mid（不能 -1）mid 及右侧全部确认 ≥ t，mid 可能就是刀痕

终止 l === r 即刀痕，取值 [0, n]（返回 n = 全体 < t）。命中「等于」不返回，继续左压。

34 组合：左边界 = lb(t)；右边界 = lb(t+1) − 1；存在检查 lb < n && a[lb] === t——一种循环走天下。
