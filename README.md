# algorithm-road · 面试向算法学习计划与刷题沉淀系统

面向「有编程基础、算法零基础」的工程师，目标是通过系统学习 + 间隔重复刷题建立面试所需的算法能力。本仓库包含两部分：

- **学习计划与理论总结**（本 README）——路线怎么定、复习机制怎么设计、为什么这样设计；
- **`algo-tracker/`**——可直接使用的刷题沉淀系统（错题本、专题笔记、进度表），配合 `algo-tracker/README.md` 的每日流程执行。

## 一、复习机制：对艾宾浩斯遗忘曲线的改造结论

艾宾浩斯（1885）的原始实验用的是「无意义音节」，测的是纯记忆保持率（20 分钟后约 58%，1 天后约 34%，6 天后约 25%）。算法学习是**理解 + 程序性技能**，目标不是「记得答案」而是「能独立写出无 bug 的代码」，因此照搬网上流传的 8 个复习点（5 分钟 / 30 分钟 / 12 小时 / 1 天 / 2 天 / 4 天 / 7 天 / 15 天）性价比很低。

但艾宾浩斯背后的两个原理对算法学习是可靠的，应保留：

1. **间隔效应**：分散复习优于集中复习；
2. **测试效应**：主动提取（重做）远优于被动重读（重看题解）。

据此得到改造版机制：**保留间隔重复的骨架，砍掉密集短间隔，加「通过判定」自适应调整，复习一律改为盲写重做。**

## 二、间隔重复规则

一道题的复习序列：**学完当天 → 次日（D+1）→ 第 3 天（D+3）→ 第 7 天（D+7）→ 第 21 天（D+21，毕业）**。

- **通过判定**：不看任何提示，20 分钟内写出并通过全部用例，且能口述时间/空间复杂度。通过才允许推进到下一个复习点；
- **卡壳**：重置为明天重做，连续通过清零，并按新表现更新卡点分类；
- **毕业**：D+21 通过后不再单独排期，之后只在 Hot100 冲刺阶段自然重现；
- 复习方式永远是**盲写重做**，不是重看题解。

卡点分三类，用于周复盘定位弱点：

| 分类 | 含义 | 对策 |
|---|---|---|
| ① 没思路 | 完全不知从哪下手 | 该专题解题模型未建立，重看专题笔记 |
| ② 有思路写不出 | 知道做法但代码写不出来 | 实现熟练度问题（多见于链表/树指针操作），多重做 |
| ③ 边界/复杂度错 | 写得出但超时或用例挂 | 适用条件理解不深，把坑补进专题笔记易错点 |

## 三、学习路线（基于代码随想录 programmercarl.com）

专题顺序：算法基础 → 数组 → 链表 → 哈希表 → 字符串 → 双指针 → 栈与队列 → 二叉树 → 回溯 → 贪心 → 动态规划 → 单调栈 → 图论，最后用 LeetCode Hot100 检验。主路线核心题量约 200 道上下（量级估计）。

节奏：**每周 6 个刷题日 + 1 天机动日（周日复盘），每天 2 道新题 + 2~4 道到期复习题，约 2~2.5 小时**。总周期约 23.5 周（5~6 个月）。

| 阶段 | 专题 | 目标周数 |
|---|---|---|
| 打地基 | 算法基础 + 数组 | 2 |
| 打地基 | 链表 | 1 |
| 打地基 | 哈希表 | 1 |
| 打地基 | 字符串 + 双指针 | 2 |
| 打地基 | 栈与队列 | 1 |
| 核心算法 | 二叉树 | 3 |
| 核心算法 | 回溯 | 2 |
| 核心算法 | 贪心 | 2 |
| 核心算法 | 动态规划 | 4 |
| 核心算法 | 单调栈 | 0.5 |
| 冲刺 | 图论（可裁剪，前端面试低频） | 2 |
| 冲刺 | Hot100 查漏补缺 | 3 |

进度校准：每两周核对一次，专题超时就顺延，优先压缩图论与 Hot100 时间来补。面试时间紧张（如 3 个月内）时，先保证前 6 个专题（到二叉树为止）+ Hot100 对应部分，图论跳过或只做 DFS/BFS。

## 四、单题 SOP（25 分钟法则）

1. 一道新题给 25 分钟独立思考；
2. 25 分钟没思路 → 直接看题解（零基础阶段这是学习，不是作弊）；
3. 看懂后**关掉题解重写**，直到 AC，绝不照抄；
4. 写完跑测试用例，追问一句「这题的关键性质是什么」（例如：二分的前提是判定单调，不只是数组有序）；
5. 卡壳题 / 看题解才做出的题 → 记入错题本，进入复习队列；一次通过且 20 分钟内搞定的题只计数，不进错题本。

## 五、三条铁律（沉淀不为「重读」服务，为「重做」服务）

1. **不抄题解、不抄代码**——完整代码永远在 LeetCode 提交记录里，誊抄是负资产；
2. **破题点必须用自己的话写，不超过 2 句**——用自己的话写不出来的地方就是还没真懂的地方；
3. **复习 = 盲写重做**，通过判定见第二节。

## 六、前端背景的学习定制

- **语言直接用 JS/TS 刷 LeetCode**，前端面试允许自选语言；注意 JS 没有内置堆（优先队列需手写）、`slice/spread/concat` 是 O(n) 拷贝、深递归会栈溢出；
- **用已有知识当锚点**：调用栈→栈、事件循环任务队列→队列、DOM 树→树的遍历、`Map/Set`→哈希表；
- **难度预警**：二叉树与动态规划是两个硬骨头（合计约 7 周），DP 初期挫败感是零基础的正常曲线。
