环形链表：快慢指针的本职

约 25 分钟 · 前置：0004（快慢指针）+ 0009（改链三步）· 实战：LeetCode 141（Easy）+ 142（Medium）· 开课仪式：口述递归版三处自补

开课仪式：先答 0009 留的三处自补

别往下滚。0009 的尾巴让你给 reverseListRec 补三个空、亲手验一遍——先口述，再对照：

  1. 何时不再递归：head === null || head.next === null 直接返回 head—— 空表和单节点天然已「反转」；再递归一层就要对 null 取 next，当场炸。
  2. 返回谁：newHead。head 已沦为整条链的尾，返回 head 等于交出去一半链表。
  3. 后两行能否换序：不能。先 head.next = null 的话，下一行 head.next.next 就是对 null 取属性——三步是依赖链，每一步的输入是上一步的保证 （quiz Q3 补课的续集：依赖链可推导、不可背）。
递归版的价值不在工程（链一长就栈溢出，工程默认迭代），在于它逼你换一种眼光： 一条链 = 一个头节点 + 一条更短的链。今天 142 的入口推导用的正是同一种 「把结构缩小一层再看」的眼光。

快慢指针，回到本职

0004 里快慢指针在数组上干的是读写分工的粗活（fast 读、slow 写）。今天它回到本职： 追及问题。slow 每轮走 1 步、fast 每轮走 2 步——

  • 无环：fast 先撞到尾，循环退出，返回 false；
  • 有环：两个都进环，fast 每轮把与 slow 的距离拉近 1 格。

有环必相遇——但这句话和 11 的「移短板必不增」同族：排除证明是证出来的，不是感觉出来的。 证明过，才配 O(1) 空间：

fast 不会跨过 slow。相对速度恒为 1 → 距离每轮恰好减 1； 距离是整数 → 必先到 0，不可能从 1 直接跳到 −1。这就是 141 的口述 gate。

决策对照表（141 判环）

决策点规则（141 环形链表）
初始化slow = head; fast = head（同一起跑线；不是 19 题「提前量」姿势，别混）
循环条件fast && fast.next —— fast 一步吃两格，两道闸都得过才准走
走法slow = slow.next; fast = fast.next.next（只走不改——全程零改链）
判定slow === fast —— 同一节点（引用相等），不是同值
终止闸关（fast 或 fast.next 为 null）→ 无环；同格 → 有环
边界空表：fast 为 null，循环不进；单节点无环：fast.next 为 null； 单节点自环：一轮走完同格——模板零特判全覆盖（连续剧第四集）

142 的两段式：一道代数题

判出有环只拿一半分——142 要交出环入口。相遇后别动 slow，放第三个指针 p1 从 head 出发，和 slow 同速走：相遇处就是入口。为什么？纸上推一遍 （环长 = b + c）：

记号含义
ahead → 入口的步数
b入口 → 相遇点的步数
c相遇点绕回入口的步数（环长 = b + c）
slow 路程a + b——slow 进环后一圈没跑完就被追上 （fast 早已进环等着，每轮拉近 1 格，最坏落后环长 − 1 格）
fast 路程a + b + n(b+c)，n ≥ 1（fast 多绕的整圈）
速度 2 倍2(a+b) = a + b + n(b+c) ⇒ a = c + (n−1)(b+c)
a = c + 整数圈 ⇒ head 到入口的距离 ≡ 相遇点到入口的距离（mod 环长）。 同速出发，少绕的整数圈恰好抵消——必在入口相遇。边界：入口就是 head（pos = 0）时， 相遇点就是 head，第二段循环零次直接返回——还是零特判。 这道代数就是快慢法 O(1) 空间买到的全部东西：别背结论，推它。
四个高频坑： ① 循环条件只写 fast——fast.next.next 对 null 取属性当场炸； fast 一步吃两格，两道闸都得有； ② 用 slow.val === fast.val 判相遇——环里可能有同值节点； 要判身份（=== 引用）：JS 里对象 === 比的是「同一个东西」，不是「内容一样」； ③ 142 相遇后让 fast 继续 2 倍速追——那还是 141 的追及，永远绕圈；第二段必须同速； ④ 想给空表/单节点加特判——先问模板能不能吞（连续剧第四集：三处边界全被模板吞掉）。

    📋 完整题面 · 141 环形链表（Easy）

    给你一个链表的头节点 head，判断链表中是否有环。

    如果链表中有某个节点，可以通过连续跟踪 next 指针再次到达，则链表中存在环。 为了表示给定链表中的环，评测系统内部使用整数 pos 来表示链表尾连接到链表中的位置 （索引从 0 开始）。注意：pos 不作为参数进行传递，仅仅是为了标识链表的实际情况。

    如果链表中存在环，则返回 true；否则，返回 false。

    示例 1：head = [3,2,0,-4]，pos = 1  → true（尾节点接到下标 1）
示例 2：head = [1,2]，pos = 0       → true（尾节点接到下标 0）
示例 3：head = [1]，pos = -1        → false（无环）

    提示：链表中节点的数目范围是 [0, 10⁴]；-10⁵ ≤ Node.val ≤ 10⁵； pos 为 -1 或者链表中的一个有效索引。

    进阶：你能用 O(1)（即，常量）内存解决此问题吗？

    📋 完整题面 · 142 环形链表 II（Medium）

    给定一个链表的头节点 head，返回链表开始入环的第一个节点。 如果链表无环，则返回 null。

    如果链表中有某个节点，可以通过连续跟踪 next 指针再次到达，则链表中存在环。 为了表示给定链表中的环，评测系统内部使用整数 pos 来表示链表尾连接到链表中的位置 （索引从 0 开始）。如果 pos 是 -1，则在该链表中没有环。 注意：pos 不作为参数进行传递，仅仅是为了标识链表的实际情况。

    不允许修改链表。

    示例 1：head = [3,2,0,-4]，pos = 1  → 返回索引为 1 的链表节点
示例 2：head = [1,2]，pos = 0       → 返回索引为 0 的链表节点
示例 3：head = [1]，pos = -1        → 返回 null

    提示：链表中节点的数目范围是 [0, 10⁴]；-10⁵ ≤ Node.val ≤ 10⁵； pos 为 -1 或者链表中的一个有效索引。
