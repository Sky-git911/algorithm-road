滑动窗口：扩张、收缩与单调性

约 25 分钟 · 前置：0004 / 0005 · 实战：LeetCode 209（Medium）· 本课同时是你的**转移测试**——新模型新题，检验「推」而不是「背」

为什么需要窗口

找「和 ≥ target 的最短连续子数组」，朴素做法是枚举所有连续子数组：两层循环， 每个窗口重新求和，O(n²)——和你 11 题初版被超时淘汰的是同一族。 滑窗的思路：窗口在数组上滑动，用一个变量增量维护窗口的和， 每个元素进窗一次、出窗一次，总共 2n 步，O(n)。

决策表：谁动、什么时候动

角色规则
r（右端·扩张）每轮必进：吞入 a[r]，sum 增量加上
l（左端·收缩）当窗口满足条件（sum ≥ target）时，用 while 持续收缩：先记录当前长度，再吐出 a[l]、l++，直到不满足
记录时机在收缩循环内记录（每次还满足条件时的窗口都是候选）；全程维护最短
终止r 走到 n；答案 = 历史最短（从未满足过 → 0）
不变量（第四种形态）：收缩结束时，[l..r] 是以 r 结尾的、还满足条件的窗口里最长不能缩的那一个—— 再缩一格就不满足。外层的 best 记录历史最短。指针三件套至此集齐：快慢（同向·读写分工）、 对撞（相向·排除一端）、滑窗（同向·张缩——l 和 r 都是「读」语义，中间那段就是窗口）。

灵魂：单调性——滑窗的营业执照

滑窗成立的前提只有一条：窗口指标随扩张只增、随收缩只减。 209 里数组全正保证了它——加一个正数和必增、吐一个正数和必减， 所以「满足条件的最小右端」随 l 增大只增不减，l 永不回头，O(n) 由此而来。 你 quiz 错的那道 Q9，考的正是这条营业执照：正数数组的和有单调性，滑窗适用； 旋转数组、无序配对、哈希分组都没有，各自的武器是对撞二分、哈希表。

四个坑（第三个是你 11 题超时的近亲）： ① 收缩用 while 不是 if——满足条件时可能能连缩好几格； ② sum 增量维护，每轮重算立刻退化 O(n²)； ③ 记录长度在收缩循环内（r−l+1），不是收缩完再记； ④ 全正数是前提——出现负数，单调性破产，滑窗直接失效（负数版是 W4 哈希周的前缀和话题）。

    📋 完整题面 · 209 长度最小的子数组（Medium）

    给定一个含有 n 个正整数的数组和一个正整数 target。 找出该数组中满足其和 ≥ target 的长度最小的连续子数组 [nums[l], nums[l+1], …, nums[r]]，并返回其长度。如果不存在符合条件的子数组，返回 0。

    示例 1：target = 7, nums = [2,3,1,2,4,3]  → 2（子数组 [4,3]）
示例 2：target = 4, nums = [1,4,4]        → 1（子数组 [4]）
示例 3：target = 11, nums = [1,1,1,1,1,1,1,1] → 0

    提示：1 ≤ target ≤ 10⁹；1 ≤ nums.length ≤ 10⁵；1 ≤ nums[i] ≤ 10⁵。 进阶：O(n) 之外，能否给出 O(n log n) 的另一解法（前缀和 + 二分，正好串起你的 0001/0002）？
