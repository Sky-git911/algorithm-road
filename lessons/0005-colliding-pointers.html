对撞指针：确定地排除一端

定位：复盘课（977 / 11 已于 2026-11-13 提前双 AC）· 约 20 分钟 · 前置：0004 快慢指针 · 本课使命：把 11 的卡点钉死 + 留档 D+21 复习

模型：两端各持一指针，每轮扔掉一端

决策点规则
初始化l = 0, r = n - 1，两端向中间相向移动
每轮判定比较两端的相关量（977 比平方、11 比高度），移动「较差」的一端
移动的合法性每次移动 = 先证明「被移出的一端不可能参与更优解」
终止两指针相遇（977 填满结果数组、11 扫完所有候选状态）
灵魂：对撞指针每一步都在做和二分同宗的事——确定地排除。 二分靠 mid 判定一次扔一半，对撞靠端点判定一次扔一格。 指针三件套你已经集齐两件：快慢（同向·读写分工）、对撞（相向·排除一端），下一件是滑窗（同向·扩张收缩）。

977：V 型数组，最大值必在两端

升序数组含负数，平方后呈 V 型（两头大、谷底小）。唯一敢用的性质是： 未处理区间的最大值必然出现在两端（最小值在谷底、位置不定，不敢用）。 所以结果数组从尾部逆序填：每轮取两端平方较大者放入 res[k--]。

两个坑：① 逆序填——正序需要「最小值在哪」这个你不知道的信息； ② JS 结果数组用 new Array(n) 预分配按序写入，别 push 更别 spread 大数组（O(n) 拷贝）。

11 盛水：为什么移短板是安全的（你卡住的地方）

面积 = min(h[l], h[r]) × (r - l)。你的初始想法「每项都要与其他项各比一次」 其实是对的做法——O(n²) 枚举确实不漏；超时说明需要 剪掉绝大部分比较，剪的依据就是排除证明：

选择后果
移长板新的高仍 ≤ 原短板（min 被短板锁死），宽还变小一格 → 面积必不增，这一轮白扔
移短板宽变小一格，但高有机会变大 → 有机会更优
所以移出短板不是「放弃了它配对的所有可能」，而是证明过它的所有可能都不超过已记录的 best—— 这正是你二分课的老朋友：「确定地排除」。枚举 n² 个状态里，被证明无用的状态一次扔掉一批，剩下的线性扫完。

    📋 完整题面 · 977 有序数组的平方（Easy）

    给你一个按非递减顺序排序的整数数组 nums，返回每个数字的平方组成的新数组， 要求也按非递减顺序排序。

    示例 1：nums = [-4,-1,0,3,10]   → [0,1,9,16,100]
示例 2：nums = [-7,-3,2,3,11]  → [4,9,9,49,121]

    提示：1 ≤ nums.length ≤ 10⁴；-10⁴ ≤ nums[i] ≤ 10⁴；nums 已按非递减排序。 进阶：设计 O(n) 的线性解法。

    📋 完整题面 · 11 盛最多水的容器（Medium）

    给定一个长度为 n 的整数数组 height。有 n 条垂线， 第 i 条线的两个端点是 (i, 0) 和 (i, height[i])。 找出其中的两条线，使得它们与 x 轴共同构成的容器可以容纳最多的水。返回容器可以储存的最大水量。 说明：你不能倾斜容器。

    示例 1：height = [1,8,6,2,5,4,8,3,7] → 49
示例 2：height = [1,1]                → 1

    提示：n == height.length；2 ≤ n ≤ 10⁵；0 ≤ height[i] ≤ 10⁴。
